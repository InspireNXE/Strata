# Getting started

These pages take you from nothing to a working screen.

1. [Installation](installation.md) covers what you need, how to build Strata, and how to depend on it from a Swing application.
2. [Your first screen](first-screen.md) builds a small form step by step and shows it in a Swing window.
3. [Core concepts](concepts.md) explains the ideas the rest of the documentation assumes: the component tree, the factory, hosts, UI units, layout passes, events and themes.

If you learn best by reading code, the `sandbox` module in the repository is a complete demo screen written against the API only. Run it with `./gradlew :sandbox:run`.
