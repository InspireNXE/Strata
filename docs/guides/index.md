# Guides

Each guide covers one part of Strata in depth: the rules, the defaults, the edge cases and working code. Every Java example on these pages is compiled and tested as part of Strata's build, so it matches the current API.

| Guide | Read it to learn |
|---|---|
| [Components](components.md) | What every component has: state flags, the tree, attachment, ids, cursors, bounds |
| [Layout](layout.md) | How sizes and positions are decided, and every container |
| [Widgets](widgets.md) | What each widget does, key by key: labels and images, buttons, check boxes, sliders, text boxes, lists, drop-downs, windows, message boxes, tabs, progress bars and separators |
| [Overlays and tooltips](overlays.md) | Popups, modal dialogs, tooltips and held modifiers |
| [Events](events.md) | Handlers, phases, cancellation, bubbling, clicks and drags |
| [Event snapshots](snapshots.md) | Comparing a component's state when an event fired with its state now |
| [Input and focus](input-focus.md) | Keys, modifiers, shortcuts, focus rules, tab order, text input |
| [Screens](screens.md) | The screen lifecycle, rebuilding, closing and stacks |
| [Themes](theming.md) | Style keys, paints, sprites and nine-slices |
| [Text](text.md) | Text styles, spans, measurement and wrapping |
| [Extending Strata](extending.md) | Behaviors, composition, custom components and custom layouts |
